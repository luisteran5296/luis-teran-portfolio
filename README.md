# Luis Terán — AI Engineer & Applied AI Specialist Portfolio

A modern, high-performance, and visually captivating portfolio built with **Vite**, **React 19**, **Tailwind CSS v4**, **Lightswind UI**, and **Framer Motion**, exported as a high-speed static web application for **Firebase Hosting**.

---

## 🚀 Key Features & Architectural Highlights

- **Hero Interactive Hanging ID Badge**: Physics-driven gravitational pendulum with real momentum and air damping, interactive drag/click gestures, and automatic initial swing on first load.
- **Productos IA (Cards Almanac)**: Scroll-driven sticky stack inspired by Textura / GetLayers. Pinned cards overlay seamlessly with subtle 3D perspective incline, peek tab headers, and interactive bookmarking.
- **Career & Education Timeline**: Ascending chronological career track with official verification links for certifications (UNAM, IBM, Coursera).
- **Specialized AI Positioning**: Tailored for roles as **AI Engineer**, **Applied AI Specialist**, and **Senior Data Scientist** (Gemini 2.5, Google Genkit, LangChain, Vertex AI, Cloud Run, BigQuery).
- **Smooth Navigation & Lenis**: Integrated with Lenis smooth scrolling, Dark/Light mode toggle, interactive custom cursor, and responsive mobile dock.
- **Bilingual (ES/EN)**: Native instant language switching between Spanish and English.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 7](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components**: [Lightswind UI](https://lightswind.dev/)
- **Animation & Physics**: [Framer Motion](https://www.framer.com/motion/), Lenis Smooth Scroll
- **Icons**: Lucide React
- **Hosting**: Firebase Hosting

---

## 💻 Local Development

```bash
npm install
npm run dev
```

The development server runs locally at `http://localhost:8080/`.

---

## 📦 Production Build & Deployment

```bash
# Build the production static distribution into out/
npm run build

# Deploy to Firebase Hosting
firebase deploy --only hosting
```
